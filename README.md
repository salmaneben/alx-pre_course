## ⚙️ Setup

To clone and explore this repository:

```bash
git clone https://github.com/salmaneben/alx-pre_course.git
cd alx-pre_course
```

### Running the Scripts

Execute the bash scripts:
```bash
# Navigate to the bash directory
cd 0x01-git/bash

# Make scripts executable
chmod +x alx school

# Run the scripts
./alx        # Output: "ALX School is so cool!"
./school     # Output: "The school is open!"
```

### Working with Git Commands

Useful commands demonstrated in this repository:
```bash
# Keep repository up to date (as shown in up_to_date file)
git pull

# Check repository status
git status

# Add files to staging
git add .

# Commit changes
git commit -m "Your commit message"

# Push to remote repository
git push origin main
```

### Prerequisites

- Git installed on your local machine
- Basic understanding of command line interface
- Text editor (Emacs, Vim, VS Code, or any preferred editor)
- Unix/Linux environment or Windows with Git Bash
